# global-sales-data-analysis
# Аналіз глобальних продажів

## Опис проєкту

Навчальний проєкт з аналізу даних про продажі міжнародної компанії, яка реалізує товари через звичайні магазини та інтернет-магазини.

Проєкт охоплює підготовку даних, дослідження продажів і пошук бізнес-інсайтів на основі даних про замовлення, товарні категорії та географію продажів.

## Бізнес-задача

Дослідити діяльність компанії на основі історичних даних про продажі, визначити ключові показники ефективності, виявити тенденції та закономірності й сформулювати висновки, які можуть допомогти в ухваленні бізнес-рішень.

## Дані

Для аналізу використовуються три таблиці:

- `events.csv` — дані про продажі за декілька років, зокрема дати замовлення та відвантаження, товарні категорії за кодами, країни, канали продажу, кількість проданих одиниць, ціни та витрати.
- `products.csv` — довідник товарних категорій та їхніх кодів.
- `countries.csv` — довідник країн, їхніх кодів, регіонів і субрегіонів.

## Інструменти

- Python — мова програмування для обробки та аналізу даних.
- Pandas — бібліотека для роботи з табличними даними.
- NumPy — бібліотека для числових операцій.
- Matplotlib та Seaborn — бібліотеки для створення візуалізацій.
- Google Colab — середовище для написання та виконання коду.

## Етапи роботи

1. **Огляд даних:** дослідження структури таблиць, колонок і зв’язків між ними.
2. **Очищення даних:** перевірка пропусків, дублікатів, типів даних, некоректних значень і можливих аномалій.
3. **Об’єднання даних:** створення єдиного набору даних на основі трьох таблиць.
4. **Аналіз продажів:** розрахунок ключових показників, дослідження доходів, витрат, прибутку та популярності товарів.
5. **Географічний аналіз:** дослідження продажів за країнами, регіонами та каналами продажу.
6. **Аналіз відвантаження:** дослідження часу між замовленням і відвантаженням та його зв’язку з прибутком.
7. **Аналіз часових тенденцій:** дослідження динаміки продажів, продажів за днями тижня та можливих сезонних закономірностей.
8. **Висновки та рекомендації:** формулювання бізнес-інсайтів на основі результатів аналізу.

## Результати

Результати аналізу, візуалізації, основні висновки та бізнес-рекомендації будуть додані після завершення дослідження.
